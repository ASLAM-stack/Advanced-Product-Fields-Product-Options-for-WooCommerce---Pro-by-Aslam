== Description ==

**Advanced Product Fields (Product Options) for WooCommerce - Pro by Aslam** allows you to add powerful, customizable product add-ons and extra options to your WooCommerce store. All features commonly locked behind commercial Pro licenses are 100% unlocked and free.

### 🌟 All Pro Capabilities Included:
* **13+ Premium Field Types**: Single-line text, textarea with live character counter, numbers, styled selects, radio pills, checkboxes, Color Swatches, Image Swatches, Add-on Quantity Steppers (+/-), Drag-and-Drop File Uploads, Date and Time pickers, and Section dividers.
* **Dynamic Pricing Models**: Flat fee, quantity-multiplied fee, percentage of base price, character-count pricing (engraving/embroidery with free character thresholds), and custom mathematical formulas (e.g. `[price] + [qty] * 2.5`).
* **Advanced Conditional Logic**: Create complex show/hide rules with AND / OR multi-rule logic that evaluates reactively on the frontend and validates on the server.
* **Live Fast-Food Order Summary**: Dynamic receipt-style breakdown calculating base price, addon adjustments, and real-time grand total.
* **Barab Fast Food Theme Styling**: Pre-packaged with the authentic aesthetic of the Barab theme (50px pill shapes, crimson & fresh herb green accents, circular steppers, and warm parchment backgrounds).
* **Visual Style Customizer**: Change presets (Barab Fast Food, Dark Grill, Fresh Bistro, Modern Clean) or customize colors, fonts, border-radii, and custom CSS anytime from WooCommerce settings.
* **High-Performance Order Storage (HPOS) Ready**: Fully compatible with WooCommerce Custom Order Tables (HPOS) and legacy post storage.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/advanced-product-fields-by-aslam` directory, or install the `advanced-product-fields-by-aslam.zip` file directly via the WordPress Plugins menu (**Plugins > Add New > Upload Plugin**).
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to **WooCommerce > Product Fields** to create your first field group.
4. Customize your styles anytime via **WooCommerce > Field Styles (Barab)**.

== Frequently Asked Questions ==

= Does this plugin work with variable products? =
Yes! When customers switch variations, the live pricing engine automatically detects the variation price and recalculates the grand total and addon fees.

= Are custom options saved in WooCommerce orders? =
Yes, all submitted options and price adjustments are saved to order line item metadata, visible in customer invoices, order emails, customer account screens, and the WordPress admin order editor.

= Can I use this on non-food stores? =
Yes! While styled by default for fast food and restaurants, you can use the built-in Style Customizer under **WooCommerce > Field Styles** to switch to modern minimalist, dark grill, or custom palettes.
